# Applications to place a person onto the Sex Offenders Register

> **WHO IS A REGISTERABLE OFFENDER?**
>
> [Section 6 SORA](https://classic.austlii.edu.au/au/legis/vic/consol_act/sora2004292/s6.html) is the legislation.
>
> Any person who has been sentenced for a registerable offence.
>
> [Class 1 offences are found in Schedule 1](https://classic.austlii.edu.au/au/legis/vic/consol_act/sora2004292/sch1.html) - serious sex offences against child - penetrative.
>
> [Class 2 offences Schedule 2](https://classic.austlii.edu.au/au/legis/vic/consol_act/sora2004292/sch2.html) - sexual offence against a child (non penetrative)
>
> Class 3 or 4 offence or any offence; an offence that results in the making of a sex offender registration order.


- The application occurs **after** sentencing.
- The court cannot consider the punitive aspect of them being placed onto the SOR in sentencing.




| Mandatory Applications | Class                                     |
| --------------------- | ----------------------------------------- |
| Adult Offender        | Class 1 or Class 2 Offence (Child Victim) |

| Discretionary Applications | Class                                         |
| ---------------------- | --------------------------------------------- |
| Adult Offender         | Any offence except a Class 1 or 2 offence |
| Juvenile Offender      | Any offence
