
| Offence                                                                          | Period   |
| -------------------------------------------------------------------------------- | -------- |
| 1x Class 1 Offence                                                               | 15 years |
| 1x Class 1 and another registerable offence                                      | Life     |
| 1x Class 2 Offence                                                               | 8 years  |
| 2x Class 2 Offences                                                              | 15 years |
| 3x Class 2 Offences                                                              | Life     |
| Juveniles = half the reporting period with a maximum of 7 and a half years (s35) |          |
- Section 34(4)
	- (a) if found guilty of a Class 3 offence, deemed to be a Class 1 offence
	- (b) if found guilty of a class 4 offence or any other offence, deemed to be a Class 2
- 2 or more offences arising from same incident within a 24 hour period and against the same victim are considered a single offence for the purposes of reporting - s 34(3) and see s5(1)
