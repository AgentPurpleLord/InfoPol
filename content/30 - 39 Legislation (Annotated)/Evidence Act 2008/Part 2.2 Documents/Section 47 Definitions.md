>1. A reference in this Part to a *document in question* is a reference to a document as to the contents of which it is sought to adduce evidence.
>2. A reference in this Part to a copy of a document in question includes a reference to a document that is not an exact copy of the document in question but that is identical to the document in question in all relevant aspects.

# Explanatory Memorandum
>*Clause 47* defines *document in question* for the purposes of Part 2.2 of the Bill. It also provides that a document is to be taken to be a copy of a document, even though it is not an exact copy, if it is identical in all relevant respects.
